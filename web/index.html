      Syntax
      
  
      
    
      LDI Rd, nRd ← n
      
    
      MOV Rd, RaRd ← Ra
      
    
      ADD Rd, Ra, RbRd ← Ra + Rb
      
    
      SUB Rd, Ra, RbRd ← Ra − Rb
      
    
      AND / OR / XOR Rd, Ra, Rbbitwise
      
    
      NOT Rd, RaRd ← NOT Ra
      
    
      INC Rd, RaRd ← Ra + 1
      
    
      SHL / SHR Rd, RbRd ← Rb shifted by 1
      
    
      LD Rd, [Ra]Rd ← M[Ra]
      
    
      ST [Ra], RbM[Ra] ← Rb
      
    
      JMP labelPC ← label
      
    
      BRZ Ra, labelif Ra = 0: PC ← label
      
    
      HALTstop
      
  
      
  
      Labels end with :, comments start with ;. Numbers: 12, 0x0C, 0b1100. R0–R3, 8-bit values.
      

      


      
  
      Program
      
  
        
  
        Parts
        
  
        
    
        01 Fetch: PC picks a line of program memory; +1 makes the next address.
        
    
        02 Decode: the instruction splits into OP, DR, SA, SB, IMM; the control ROM turns OP into the control word.
        
    
        03 Register file: MUX A and MUX B read two registers; the decoder picks the one that loads.
        
    
        04 Execute: ALU or shifter; MUX B swaps in the constant.
        
    
        05 Memory: LD reads and ST writes at address A.
        
    
        06 Write back: MUX D puts the result on Bus D for the destination register.
        
    
        Keys: → step · space run · R reset · 1–4 program · S speed · C code · T theme
